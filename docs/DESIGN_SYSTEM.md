# Admity — Design System (Brilliant-style)

> Источник эстетики: приложение **Brilliant** (референсы 1–10) + тренды Onix EdTech.
> Цель: чистый, геймифицированный, «не AI slop». Этот файл — единственный источник правды
> по визуалу. Все агенты обязаны читать его перед версткой. Цвета даны как Dart-константы.

---

## 0. Принципы (из Brilliant + Onix)

1. **Less is more.** Максимум воздуха, минимум элементов на экране. Один акцент на экран (Hick's Law).
2. **Геймификация:** стрик, XP, уровни, узловой путь уроков, прогресс-кольца, бейджи.
3. **Микроуроки:** короткие шаги, по одному действию на экран, мгновенный фидбэк (✓/✗).
4. **Conversational AI (Ералы):** дружелюбный помощник, который ведёт диалог, а не выдаёт стену текста.
5. **3D-иллюстрации** как смысловые иконки разделов (изометрия, мягкие тени).
6. **Жирная геометрическая типографика** + чистые карточки со скруглением и мягкой тенью.

## 1. Цвета (Brilliant-accurate)

```dart
// lib/core/theme/app_colors.dart
class AppColors {
  // Бренд
  static const primary       = Color(0xFF4255FF); // кобальт (выделение, активная вкладка)
  static const primaryDark   = Color(0xFF2B3CC9); // нажатое состояние
  static const navyDeep       = Color(0xFF14246B); // тёмная грань 3D-иллюстраций

  // Акценты
  static const accentLime    = Color(0xFFC2F03C); // молния/стрик (жёлто-зелёный)
  static const successGreen  = Color(0xFF1FD65F); // прогресс, «верно»
  static const mascotGreen   = Color(0xFF35D24A); // цвет фигуры-плейсхолдера маскота
  static const goldKey       = Color(0xFFFFB020); // ключи/валюта
  static const errorRed      = Color(0xFFE5484D); // «неверно»

  // Текст
  static const ink           = Color(0xFF16161D); // заголовки, тёмные кнопки
  static const inkSecondary  = Color(0xFF5B5F6B); // подписи

  // Поверхности
  static const white         = Color(0xFFFFFFFF);
  static const surfaceTint   = Color(0xFFF4F6FB); // фон вкладок/секций
  static const border        = Color(0xFFE7E9F0);
  static const cardShadow    = Color(0x14101828); // мягкая тень карточек

  // Градиент «featured CTA» (кнопки Jump ahead / Start the Lesson)
  static const ctaGradient = [
    Color(0xFF6E8BFF), Color(0xFFB07BFF), Color(0xFFFF7BC4), Color(0xFFFFB14E),
  ]; // blue → purple → pink → orange, слева направо
}
```

**Правило кнопок (важно — так в Brilliant):**
- Обычное действие (Continue / Check / Finish / Сохранить) — **сплошная тёмная** `ink`, текст белый, скругление 16.
- Главное/праздничное действие (Jump ahead / Start the Lesson / завершение урока) — **многоцветный градиент** `ctaGradient`.

## 2. Типографика — ОБЯЗАТЕЛЬНО с кириллицей

Brilliant использует жирный геометрический гротеск. У нас контент на русском/казахском,
поэтому шрифт **обязан** поддерживать кириллицу. Plus Jakarta Sans / Poppins НЕ подходят (нет кириллицы).

- **Display (заголовки):** `Onest` 700/800 (полная кириллица, геометрический, близок к Brilliant).
- **Body/UI:** `Onest` 400/500/600.
- Фолбэк: `Manrope` (тоже кириллица).
- Подключать через `google_fonts` или локальные `.ttf` в `assets/fonts/`.

```
Type scale (logical px):
  display    34 / w800 / -0.5 ls   — экран-интро урока («Comparing Likelihoods»)
  h1         26 / w800 / -0.3 ls   — заголовки экранов
  h2         20 / w700             — заголовки карточек/секций
  title      17 / w700             — название урока в боксе
  body       16 / w500
  label      14 / w600             — кнопки, табы
  caption    13 / w500 / inkSecondary
```

## 4. Базовые компоненты (`lib/shared/widgets/`)

- `AppScaffold` — SafeArea + единый фон.
- `PrimaryButton` (тёмная) и `FeaturedButton` (градиент `ctaGradient`).
- `AppCard` — белая карточка, radiusLg, мягкая тень, padding 16.
- `StreakBadge` — пилюля с молнией `accentLime` + число дней (правый верхний угол).
- `KeyBadge` — пилюля с ключом `goldKey` + число (левый верхний угол).
- `ProgressRing` — кольцо прогресса (как 82% в референсах).
- `LessonNode` — круглый «диск-платформа» узла пути (активный — синее кольцо `primary`, выполненный — заливка, закрытый — серый).
- `TopicDiagramSlot` — слот под 3D-диаграмму раздела (пока плейсхолдер, см. §6).
- `MascotSlot` — слот под маскота (пока геометрическая фигура, см. §6).
- `AppBottomNav` — 5 вкладок (см. §5).

## 5. Навигация (исправление текущего скаффолда)

Текущий скаффолд имеет вкладки: Главная / Шансы / Учёба / Ералы / Профиль — это не совпадает с ТЗ.
**Правильные 5 вкладок:**

| # | Вкладка | Маршрут | Содержание |
|---|---------|---------|-----------|
| 1 | **Главная** | `/home` | Стрик, задание на сегодня, календарь сегодняшних дел |
| 2 | **Курсы** | `/courses` | Brilliant-стиль: путь уроков, уровни, 3D-диаграммы |
| 3 | **Ералы** ⭐ | `/mentor` | AI-помощник (акцентная центральная вкладка) |
| 4 | **Возможности** | `/opportunities` | Стипендии, университеты, мероприятия, идеи проектов |
| 5 | **Профиль** | `/profile` | Настройки, данные о себе, заметки, документы-пакет (локально) |

«Университеты» и «Шансы» — это разделы внутри **Возможностей**, не отдельные вкладки.

## 6. Плейсхолдеры (маскот и 3D) — по требованию заказчика

Заказчик добавит маскота и финальные 3D/анимации сам. Сейчас везде ставим аккуратные плейсхолдеры:

- **`MascotSlot`**: мягкая геометрическая фигура-«ромб/блоб» в `mascotGreen` (силуэт как у Brilliant),
  по центру маленькая нейтральная метка. Параметры `size`, `tag` (чтобы потом найти все места).
  Ставить везде, где по сценарию будет маскот.
- **`TopicDiagramSlot`**: скруглённый квадрат с лёгким градиентом `primary→navyDeep`,
  внутри простая изометрическая фигура (куб/сфера) — заглушка вместо 3D-иллюстрации раздела.

Оба виджета помечать `// TODO(mascot)` / `// TODO(3d)` — чтобы заказчик быстро нашёл и заменил.

## 7. Экраны — спецификация (по описанию заказчика)

### 7.1 Splash (`/`)
Название «Admity» по центру → по нему слева-направо проходит блик света → надпись «улетает» вверх →
открывается Главная. (Сейчас — статичная версия; саму анимацию делает motion-агент позже.
Сейчас просто оставить структуру и `// TODO(motion): light sweep + fly-up`.)

### 7.2 Главная (`/home`)
- Сверху: приветствие + `StreakBadge`.
- Карточка «Задание на сегодня» (название + кнопка перехода в урок).
- Календарь/лента дел на сегодня (чекбоксы).
- `MascotSlot` рядом с приветствием.

### 7.3 Курсы (`/courses`) — ядро Brilliant-стиля
- Верх: горизонтальные табы курсов (Математика/…); под выбранным — синяя полоса (реф. 7/8).
- По центру вверху — **название сегодняшнего курса/задания**, ниже — **Level**.
- В центре — **3D-диаграмма раздела** (`TopicDiagramSlot`), **свайп вправо** = выбрать сегодняшний урок.
- Узловой путь уроков (`LessonNode`) — вертикальный, как реф. 1/9/10.
- Внизу каждой страницы — **бокс**: слева 3D-диаграмма (`TopicDiagramSlot`), по центру название урока;
  под боксом — `FeaturedButton` «Start the Lesson». Тап → `MascotSlot` «летит вниз» (анимация позже) → `/lesson`.

### 7.4 Урок (`/lesson`)
Brilliant-механики: интро урока (display-заголовок + иллюстрация) → шаги с выбором ответа
(карточки, Draw/Check) → фидбэк ✓/✗ с «Why?» → экран «Lesson complete!» с XP и `MascotSlot`.

### 7.5 Ералы — AI (`/mentor`)
- Чат с дружелюбным помощником (conversational design).
- **Создание событий в календаре:** AI предлагает несколько мероприятий → пользователь ОБЯЗАН нажать
  «Проверить все мероприятия» → может изменить время каждого (всё гибко) → сохранить → события уходят в календарь.
- **План по теме (напр. IELTS):** AI задаёт наводящие вопросы (ресурсы, сколько времени, доступ к интернету) →
  выдаёт точный поурочный план + ресурсы (по возможности — внутри приложения).
- `MascotSlot` как аватар помощника.

### 7.6 Возможности (`/opportunities`)
- Стипендии + университеты; фильтр/сортировка по: город, направление, цена, доступность, требуемые документы.
- Открыть стипендию → требования, что покрывает, как получить, какие статы нужны + как их добить.
- Подача заявки прямо в приложении (заполнение полей).
- Раздел «Мероприятия рядом» и «Идеи проектов» по направлению ученика.

### 7.7 Профиль (`/profile`)
- Настройки, редактирование данных о себе (изменить/добавить/сохранить).
- Заметки о себе.
- Документы как **пакет** (чтобы отправлять разом без возни).
- Все изменения хранятся **локально** (Hive/Isar/Drift) для скорости; синк с Supabase — опционально позже.

## 8. Анти-slop чек-лист (ревью каждого экрана)

- [ ] Один акцент на экран, остальное тихо.
- [ ] Цвета только из `AppColors`, шрифт только `Onest`.
- [ ] Тёмная кнопка для обычных действий, градиент — только для featured.
- [ ] Скругления и тени из токенов (мягкие), без жёстких границ.
- [ ] Нет дефолтного фиолетового Material, нет `Colors.deepPurple`, нет generic-карточек.
- [ ] Кириллица рендерится корректно (KZ + RU).
- [ ] Прокручиваемые экраны: `SafeArea > SingleChildScrollView > Column(.min)` (анти-gotcha).
