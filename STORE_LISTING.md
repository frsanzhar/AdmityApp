```
Admity — честный помощник для поступления в вуз

Приложение для школьников 8–12 классов Казахстана, которые хотят поступить в казахстанский или зарубежный университет на грант или бюджет.

─────────────────────────────
КАТАЛОГ ВУЗОВ КЗ И ЗА РУБЕЖОМ
─────────────────────────────
• Честные данные: минимальные баллы ЕНТ и ГПА по каждой специальности — с указанием источника, без приукрашивания.
• Гранты и стоимость обучения: реальные пороги для государственных грантов по конкретным ГОП.
• Зарубежные вузы: топ-программы для поступающих из Казахстана.
• Отфильтруй вузы по направлению, баллам и стоимости — и сразу увидь, куда ты проходишь.

─────────────────────────────
ЕРАЛЫ — ИИ-НАСТАВНИК
─────────────────────────────
Ералы отвечает на вопросы об экзаменах, вузах и стипендиях — и помогает тебе думать самостоятельно.

• Направляет и задаёт вопросы, а не делает за тебя.
• Никогда не пишет эссе целиком — только разбирает структуру, идеи, ошибки.
• Предлагает конкретные события в календарь (с твоего подтверждения).
• Работает на русском, казахском и английском.

Твои данные защищены: Ералы не получает твоё имя, email или точный ГПА — только обезличенный контекст профиля.

─────────────────────────────
ПЛАН ПОДГОТОВКИ
─────────────────────────────
• Ералы составляет поурочный план под твои материалы и расписание.
```

## App Review Notes
*(English, for the Apple reviewer)*

```
Thank you for reviewing Admity.

Language: The app is in Russian, targeting Kazakhstan schoolchildren (grades 8–12). The UI is fully Russian-language by design.

Guest mode (no account needed):
1. Launch the app.
2. Tap "Продолжить как гость" (Continue as Guest) on the welcome/onboarding screen.
3. You can browse the universities catalog, take the career test, and explore the app without creating an account.

AI mentor (requires sign-in):
1. Create an account with any email address, or use Sign in with Apple.
2. Navigate to the "Ералы" tab (chat icon in the bottom navigation).
3. The AI mentor feature requires a live Supabase Edge Function connection. If the server is unreachable, the app displays a friendly offline fallback response — this is expected behaviour.

No demo account is required. The app works fully in guest mode for most features.

Note on data: The app collects only what the user voluntarily provides (email for sign-in, optional profile fields). No advertising SDKs, no analytics, no third-party tracking. Attached documents stay on-device only. The LLM API key is server-side only and is never embedded in the app binary.
```
